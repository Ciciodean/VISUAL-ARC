# VISUAL ARC — Personal Free Unlimited PDF417 Generator

100% free personal tool. Unlimited use. No credits. No payments.

## Deploy on Render (static site)
1. Push this folder as its own GitHub repo (e.g. `VISUAL-ARC`).
2. On Render: New + → Static Site → select this repo.
3. Settings:
   - Build Command: (empty)
   - Publish Directory: `./`
4. Deploy. Done.

This repo is fully separate from the main paid production tool.
It does NOT affect the paid tool in any way.
